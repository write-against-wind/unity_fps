# VR球棒设置完整指南

## 🎯 你需要做的步骤

### 1. 为球棒添加脚本
1. **选中你的球棒物体**
2. **在Inspector中点击 "Add Component"**
3. **搜索并添加 `VRBatWeapon` 脚本**

### 2. 配置球棒参数
在Inspector中设置以下参数：

#### 伤害设置
- **Min Damage (最小伤害)**: `20` 
- **Max Damage (最大伤害)**: `40`
- **Min Swing Velocity (最小挥动速度)**: `2`
- **Damage Cooldown (伤害冷却)**: `0.8`

#### 音效设置（可选）
- **Hit Enemy Sound**: 拖拽击中敌人的音效文件
- **Hit Object Sound**: 拖拽击中物体的音效文件

#### 特效设置（可选）
- **Hit Effect**: 拖拽击中特效预制体

### 3. 确保敌人设置正确

#### 3.1 敌人标签设置
**重要！** 你需要确保所有敌人物体的标签设置为 `"Enemy"`：

1. **选中敌人物体**
2. **在Inspector顶部找到 "Tag" 下拉菜单**
3. **选择 "Enemy" 标签**
4. **如果没有 "Enemy" 标签，需要创建：**
   - 点击 "Tag" 下拉菜单
   - 选择 "Add Tag..."
   - 点击 "+" 号
   - 输入 "Enemy"
   - 保存后回到敌人物体，选择 "Enemy" 标签

#### 3.2 敌人碰撞器设置
确保敌人有碰撞器组件：
- **Capsule Collider** 或 **Box Collider**
- **不要勾选 "Is Trigger"**（因为球棒使用OnCollisionEnter）

### 4. 球棒组件检查
确保你的球棒有以下组件（你已经设置好了）：
- ✅ **Rigidbody** 
- ✅ **VR Interactable Object**
- ✅ **Box Collider**（不要勾选Is Trigger）
- ✅ **VRBatWeapon** 脚本（新添加的）

### 5. 测试功能

#### 5.1 在Unity编辑器中测试
1. **运行游戏**
2. **用VR手柄抓取球棒**
3. **挥动球棒击中敌人**
4. **查看Console窗口的调试信息**

#### 5.2 调试信息
脚本会在Console中显示：
- "VR球棒武器初始化完成"
- "球棒被抓取"
- "球棒被释放"
- "挥动速度太慢: X.XX < 2.00"（如果挥动太慢）
- "球棒击中敌人 XXX！造成 XX.X 点伤害（速度: X.XX）"

## 🔧 可能遇到的问题

### 问题1：球棒不能造成伤害
**解决方案：**
- 检查敌人标签是否为 "Enemy"
- 检查挥动速度是否足够（至少2.0）
- 检查敌人是否有Enemy.cs脚本

### 问题2：没有音效
**解决方案：**
- 确保拖拽了音效文件到对应槽位
- 检查AudioSource组件是否正常

### 问题3：没有震动反馈
**解决方案：**
- 确保使用的是XR Toolkit的控制器
- 检查VR设备是否支持震动

### 问题4：球棒抓取有问题
**解决方案：**
- 检查VR Interactable Object脚本设置
- 确保球棒的Collider没有勾选Is Trigger

## 🎮 使用方法

1. **抓取球棒**：用VR手柄靠近球棒，按下抓取键
2. **挥动攻击**：快速挥动手柄，速度要超过设定的最小值
3. **击中敌人**：球棒碰撞到敌人时会自动造成伤害
4. **释放球棒**：松开抓取键释放球棒

## 📊 伤害计算公式

```
最终伤害 = 随机伤害(最小伤害, 最大伤害) × 速度倍数
速度倍数 = 当前挥动速度 / 最小挥动速度（限制在1.0-2.5倍之间）
```

例如：
- 挥动速度2.0，速度倍数 = 1.0倍
- 挥动速度4.0，速度倍数 = 2.0倍  
- 挥动速度5.0+，速度倍数 = 2.5倍（上限）
