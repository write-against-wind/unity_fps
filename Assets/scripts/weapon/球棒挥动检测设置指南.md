# 球棒挥动检测设置指南 - 旋转+距离检测版本

## 🎯 问题解决

现在球棒使用了**基于旋转+距离的智能挥动检测系统**，完美解决了以下问题：
- ✅ 只有真正挥动时才造成伤害
- ✅ 区分"移动球棒"和"挥动球棒"
- ✅ 避免行走时误触发攻击
- ✅ 检测真实的挥棒动作
- ✅ **新增：只有接近敌人时才攻击，远离时不攻击**

## ⚙️ 新的挥动检测参数

### 基础设置
- **Min Damage/Max Damage**: 伤害范围设置
- **Damage Cooldown**: 防止连续伤害同一敌人

### 🔄 旋转检测设置
- **Min Angular Velocity (最小角速度)**: `90°/s`
  - 球棒旋转的最低速度要求
  - 数值越大，需要挥动得越快

- **Angular Acceleration Threshold (角加速度阈值)**: `50°/s²`
  - 检测主动挥动的角加速度要求
  - 用于识别"开始挥动"的动作

- **Position Velocity Threshold (位置速度阈值)**: `1.5`
  - 配合旋转检测的位置移动要求
  - 防止原地旋转被误认为挥动

- **Swing Cooldown Time (挥动冷却时间)**: `0.3s`
  - 两次有效挥动之间的最小间隔

### 📏 距离检测设置
- **Enable Distance Check (启用距离检测)**: `true`
  - 是否检测球棒与敌人的距离变化
  - 关闭后只使用旋转检测

- **Approach Velocity Threshold (接近速度阈值)**: `0.5`
  - 球棒接近敌人的最小速度要求
  - 数值越大，需要更快地接近敌人

## 🎮 挥动检测原理

### 系统检测四个关键要素：
1. **角速度检测** - 球棒是否在旋转
2. **位置速度检测** - 球棒是否在移动
3. **角加速度检测** - 是否在主动加速挥动
4. **🆕 距离检测** - 球棒是否在接近敌人

### 有效挥动的条件（必须同时满足）：
- ✅ **角速度** > 最小角速度 (90°/s)
- ✅ **位置速度** > 位置速度阈值 (1.5)
- ✅ **🆕 接近敌人** > 接近速度阈值 (0.5)
- ✅ **满足以下任一条件**：
  - 角加速度 > 阈值（主动挥动）
  - 角速度 > 最小值 × 1.5（高速挥动）

## 🔧 参数调试建议

### 如果球棒太敏感（轻微动作就攻击）：
```
Min Angular Velocity: 120°/s ↑
Angular Acceleration Threshold: 80°/s² ↑
Position Velocity Threshold: 2.0 ↑
Approach Velocity Threshold: 1.0 ↑
Swing Cooldown Time: 0.5s ↑
```

### 如果球棒不够敏感（用力挥动也不攻击）：
```
Min Angular Velocity: 60°/s ↓
Angular Acceleration Threshold: 30°/s² ↓
Position Velocity Threshold: 1.0 ↓
Approach Velocity Threshold: 0.3 ↓
Swing Cooldown Time: 0.2s ↓
```

### 推荐的平衡设置：
```
Min Angular Velocity: 90°/s
Angular Acceleration Threshold: 50°/s²
Position Velocity Threshold: 1.5
Approach Velocity Threshold: 0.5
Swing Cooldown Time: 0.3s
Enable Distance Check: true
```

## 💡 使用技巧

### ✅ 有效的攻击方式：
- **向前挥棒** - 旋转+接近敌人
- **侧向击打** - 从侧面接近并旋转
- **上挥下砸** - 从上方接近并旋转
- **刺击动作** - 直线接近+旋转

### ❌ 无效的动作：
- **后撤挥动** - 远离敌人时挥动
- **侧向划过** - 与敌人平行移动
- **原地旋转** - 只有旋转没有接近
- **直线推动** - 只有接近没有旋转

## 🎯 距离检测的优势

### **旧版本问题**：
- ❌ 挥动时远离敌人也会攻击
- ❌ 无法区分"攻击性挥动"和"防御性挥动"
- ❌ 不符合真实的击打逻辑

### **新版本优势**：
- ✅ **真实击打感** - 必须接近敌人才能攻击
- ✅ **防御性挥动** - 后撤挥动不会误伤
- ✅ **精确攻击** - 只有向敌人挥动才有效
- ✅ **战术性** - 可以做出防御性动作

## 🔧 高级设置

### 如果想要更宽松的距离检测：
```
Enable Distance Check: false  // 完全关闭距离检测
```

### 如果想要更严格的距离检测：
```
Approach Velocity Threshold: 1.0 ↑  // 需要更快地接近
```

现在你的球棒不仅能检测真实的挥动，还能区分攻击性和防御性的动作！
